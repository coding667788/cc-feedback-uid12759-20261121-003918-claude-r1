为离线灾备演练实现密钥托管轮换审计器。轮换期间，某些时间段内旧代和新代都要能独立凑齐恢复门槛，而且一次双代恢复中，同一个人只能参加一代、只能交付一份分片。托管点共用机房、电源或值班团队，单个故障域停摆可能同时让多份副本不可用。审计器要找出隐藏在交接时间和共同故障中的缺口，并从已批准的候选动作中求出能覆盖整个演练的最低成本修复。输入里的分片、人员和故障域都用虚构标识，仅模拟可用性和职责分离。

使用 Windows 原生 Python 3.12、标准库和 CPU，从空仓库实现。提供 `python -m rotation_audit audit CASE.json` 和 `python -m rotation_audit repair CASE.json`，分别输出基线审计和最优修复 JSON。README 给出输入输出字段、退出码、命令和重跑方法。交付可直接运行的样例和 `python -m unittest discover -s tests -v` 测试。

输入是一场演练，含整数时刻 start、dual_start、switch、dual_end、end，满足 start ≤ dual_start < switch < dual_end ≤ end。所有区间左闭右开，演练外不判定。switch 之前要求旧代、从 switch 起要求新代，双代窗口 [dual_start, dual_end) 内同时要求两代。每代独立声明其分片集合及正整数门槛。输入还包括故障域表、预算 b（0 到 2）、现有副本及备选动作。每份副本声明唯一 ID、所属代、分片、保管人、依赖的故障域集合，以及一个或多个可用区间；同一副本的区间取并集。每个动作具有唯一 ID、正整数成本和一份待增设的完整副本。候选副本 ID 与所有现有及其他候选副本 ID 互异，不改变任何已有副本。输入给出最多可选的动作数 k（0 到 4）。标识只用 ASCII 字母、数字、下划线、连字符，按区分大小写的字典序比较；保管人跨代用同一命名空间。拒绝重复 JSON 键、重复声明、未知引用、布尔型整数以及倒置、空或超出演练的区间；同一副本有重叠、相邻或相同的可用区间是合法输入。

把演练按五个时刻及所有现有及候选副本的可用区间端点切成最小非空时间段。两条命令始终用同一分段，即使某候选最终未选。每段枚举故障域表中从空集到 b 个域的所有组合。副本在当前段可用且依赖域与故障集合无交集时，才可用于恢复。一个恢复见证选出每个当期要求代恰好门槛数的副本，同代分片 ID 不重复，所有当期要求代合起来保管人不重复。同一分片的多份副本可作为备选，但最多选其中一份。不同时间段、不同故障情况下可以采用不同见证。两代各自能恢复，仍可能因为共同保管人而无法完成同一次双代恢复。

audit 输出全部场景。时间段按起点升序，段内故障集合按集合大小、再按域 ID 升序组成的元组排序。可恢复时返回选中的副本 ID；每代内部升序、旧代在新代前，取所有完整见证中按这个嵌套列表字典序最小的一组。不可恢复时返回按相同规则组织的最大部分见证，以及每个要求代离门槛差几份。部分见证对每代至多选到该代门槛，仍满足人员和分片约束；先最大化合计已选份数，再按嵌套列表字典序取最小。仅输出当期要求的代，某要求代未选到副本时保留其空列表。汇总给出所有场景是否通过及第一个失败场景，全部通过时首败为 null。

repair 要选一个固定的动作集合，由它和基线副本一起通过所有段、所有故障组合。先最小化总成本，再最小化动作个数，最后比较升序动作 ID 列表。基线已全部通过时返回空动作集合和零成本；无解时返回 impossible，不把某个无法证明全局最优的方案当结果。最优解同时附上选定方案按 audit 同口径生成的完整场景结果。支持至多 10 个故障域、16 个候选动作、60 份现有副本、每代 10 枚分片、切分后 24 段；避免在审计和每个候选方案中反复枚举完整副本选法，README 说明搜索状态、剪枝条件及为何不漏掉最优解。

样例从 start=0、dual_start=4、switch=5、dual_end=6、end=10 起步。无故障，每代门槛为 2；旧代两枚分片分别只有 A、B 保管，新代两枚分别只有 A、C 保管，四份副本全程可用。构造三个候选动作，都给新代由 A 保管的分片增设由 D 保管的副本。前两个动作 ID 不同、成本相同，都覆盖 [4,6)；第三个更便宜，只覆盖 [5,6)。断言基线首败在 [4,5)，修复选中覆盖完整窗口且动作 ID 较小的一项。再补上跨站点共用故障域、单域全过但域对组合失败、同一分片的副本不可凑数、两段各有可选动作但 k 限制下无统一方案、部分见证并列、相邻区间的边界、输入顺序打乱后输出一致等验证。另写一个仅用于测试的小规模穷举对照，独立枚举见证和动作集合，固定种子比较 audit 和 repair 的完整结果。
